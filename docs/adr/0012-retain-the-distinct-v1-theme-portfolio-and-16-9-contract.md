# Retain the distinct v1 Theme portfolio and the 16:9 contract

The built-in portfolio offers distinct visual treatments on the same renderer
geometry. Science, Paper Chalk, Wedding, Dark Splash, and SV illustrate the
range; Signal, Tidal, Kiln, Prism, and Blueprint add further choices. The
[Theme inventory](../theme-inventory.md) lists every shipped package.

Each Theme preserves a separate product role:

- Science is the restrained, neutral scientific/editorial default.
- Paper Chalk is a field notebook for exploratory technical work.
- Wedding is a formal invitation folio for personal or event-led talks.
- Dark Splash is a dark, luminous constraint atlas for night-room technical
  presentations.
- SV is a light-first propagation workbench with a visible trace bus and
  squared data surfaces.

Shared renderer geometry and the `scientific-data` module are implementation
reuse, not evidence of redundant expression. Dark Splash and SV remain
complementary dark-first and light-first choices.

Theme API v1 supports only 16:9 and equivalent ratios. Every
maintained example and comparison fixture is 16:9, and the current composition
field, print page, PDF validation, and raster publication contract are
16:9-specific. A real non-16:9 Deck and venue requirement must precede a
separate model-to-PDF design. Accepting additional metadata
without Output-target and Theme evidence would not constitute support.

The portfolio decision does not approve the provisional room profile or replace
room-scale review for a specific Deck.
